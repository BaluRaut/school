📚 अभ्यासक्रम — बारा मॉड्यूल

मॉड्यूल उघडण्यासाठी क्लिक करा. तास हे प्रामाणिक अंदाज आहेत: वाचन + प्रयोग करणे.

🪪 मॉड्यूल 1 — AWS: IAM, EC2 & कॅम्पस 25 धडे · 8 आठवडे · ~16 तास

भाग 1 — ओळख: root ची मास्टर किल्ली, users & groups, policy चिठ्ठ्या, टोपीसारखे roles, मशीनची ओळख, स्वच्छता. भाग 2 — संगणक: instances, प्रकार & किंमत, जोडणी (SSH विरुद्ध SSM), security groups, EBS/snapshots/AMIs, user-data & fleets. भाग 3 — कॅम्पस: VPC, S3, load balancers, Route 53, RDS, CloudWatch, Lambda, आणि बिल वाचणे. भाग 4 — दारे, रस्ते & पहारेकरी: subnet networking (NACLs, endpoints), NAT gateway, Route 53 routing policies, WAF & Shield, API Gateway. लॅब Terraform + CLI मध्ये, छोट्या आणि नेहमी नष्ट केलेल्या.

  • Kubernetes वर workload deploy करा, debug करा, वाढवा आणि अपग्रेड करा
  • तीच pipeline GitHub Actions, CircleCI, GitLab CI किंवा Jenkins मध्ये चालवा — मंजुरीच्या गेटसह आणि साठवलेल्या keys शिवाय
  • drift-मुक्त GitOps ने git मधून deployment चालवा
  • क्लाउड बिलातील चार ठरलेल्या पैशांच्या गळत्या शोधा

AI ट्रॅकनंतर

  • टोकन → attention → RLHF हातवारे न करता समजावून सांगा
  • RAG पाइपलाइन डिझाइन करा आणि ती कधी बिघडेल हे ओळखा
  • MCP वरून मॉडेलला खऱ्या साधनांशी जोडा — तुम्ही वायर वाचली आहे
  • guardrails असलेला AI एजंट बनवा (आणि कधी बनवू नये हेही जाणा)

❓ FAQ

हे खरंच मोफत आहे? काही मेख आहे का?
खरंच मोफत, MIT परवाना, नोंदणी नाही, ईमेल गोळा करणे नाही, काही विकणे नाही. एकमेव खर्च म्हणजे ऐच्छिक AWS प्रयोगांचे काही पैसे (खर्च-शिस्तीच्या पहिल्या धड्यात शिकवलेल्या $5 च्या अलार्मसह). मेख एवढीच: तुमच्या मागे कोणी लागत नाही — अभ्यास योजनेतील खुणा हीच तुमची जबाबदारी. 😄
कोर्स कोणत्या क्रमाने करावेत?
Ops ट्रॅक क्रमाने (AWS → Docker → Kubernetes → CI/CD → ArgoCD) — प्रत्येक आधीच्यावर उभा आहे. AI ट्रॅक क्रमाने (AI → VectorDB → MCP → Agents). दोन ट्रॅक स्वतंत्र आहेत; हवे तसे आलटून-पालटून करा. पूर्ण नवशिके? Docker च्या धडा 01 पासून सुरू करा — ते सर्वात सोपे दार आहे.
संपूर्ण प्रोग्रामला किती वेळ लागतो?
आठवड्याला 2–4 छोट्या सत्रांनी ~42 आठवडे; एक ट्रॅक ≈ 13–29 आठवडे; एका ट्रॅकवर पूर्णवेळ लक्ष दिल्यास ≈ 5–7 आठवडे. अंतिम मुदती नाहीत, बॅच नाहीत — ब्रँच तुमची वाट पाहतात.
काही install करावे लागेल का?
git + टर्मिनल नेहमी; CI/CD प्रयोगांसाठी मोफत GitHub खाते (fork); Docker/k8s प्रयोगांसाठी Docker Desktop; AI बाजूच्या रेपोंसाठी Python 3 (फक्त stdlib — कधीही pip install नाही); AWS प्रयोगांसाठी Terraform + AWS खाते. प्रत्येक धडा त्याला नेमके काय लागते ते सांगतो.
चूक सापडली — काय करू?
प्रत्येक पानाच्या तळाशी त्या कोर्सच्या GitHub issues ची 🐛 लिंक आहे. दुरुस्त्या हा शाळेचा सर्वात आवडता गृहपाठ आहे.
🤝 प्रामाणिकपणाचा कोपरा: हा प्रोग्राम एका व्यक्तीने बनवलेले, ओपन-सोर्स अभ्यास साधन आहे — मान्यताप्राप्त संस्था नाही. इथे मदतीला शिक्षक नाहीत, क्रमवारी नाही, नोकरीची आकडेवारी नाही, आणि रेटिंग नाही. जे आहे ते: प्रत्येक धडा सार्वजनिक, प्रत्येक आकृती तपासता येणारी, कोडची प्रत्येक ओळ चालवता येणारी, आणि यापैकी कशाबद्दलही खोटे बोलू न शकणारा git इतिहास.
